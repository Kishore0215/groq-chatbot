\# My Groq AI Chatbot



This is my first AI chatbot project. I built it to learn how AI chat applications actually work behind the scenes — connecting a web page to a real LLM (large language model) and making it remember the conversation.



I'm a 3rd year B.E. Computer Science Engineering student, and this was a beginner project for me to understand Python, Streamlit, and API integration.



\## What it does



\- You can chat with an AI in a simple web interface

\- It remembers what you said earlier in the conversation

\- Replies are generated using Groq's API (fast LLM inference)



\## Tools I used



\- Python

\- Streamlit (for the web interface)

\- Groq API (to talk to the AI model)

\- python-dotenv (to keep my API key safe/hidden)
